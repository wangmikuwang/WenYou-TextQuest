# 文游 · 文字游戏（WenYou TextQuest）

一款 **Material You / Material 3** 风格的 Android 文字游戏平台（Kotlin + Jetpack Compose），
围绕三个自由：**自己编剧情、自己造角色、自选接入 AI 品牌**。纯分支剧本完全离线可玩；
接入 AI 后获得「AI 场景生成」与「AI 导演自由模式」。

工程位置：`F:\OneDrive\Documents\harness\WenYouTextQuest`（本目录）。

## 2. 界面结构

- **主页**：快速开始 / 继续存档 / 配置 AI 提示
- **剧情**：剧情库、节点式可视化编辑（类型、正文、角色、选项、条件、效果、AI 生成指令）
- **角色**：角色卡列表与编辑
- **AI 服务**：接入多品牌、设默认、测试连接
- **设置**：Material You 外观（跟随系统/浅色/深色、动态取色开关）、默认服务、数据备份
- **对局页**：阅读叙事 → 点选项 / AI 选项 / 自由输入；结局面板；随时存档重开

## 3. 快速开始（Android Studio）

1. 用 **Android Studio（Ladybug 或更新，内置 JDK 17+）** 打开本目录 `WenYouTextQuest`。
2. 等待 Gradle 同步（AGP 8.5.2 / Kotlin 2.0.20，仓库已含 wrapper）。
3. 连接设备/模拟器（建议 Android 12+ 体验动态取色），Run ▶ `app`。
4. 打开内置示例「雨夜咖啡馆」直接玩（离线）；想体验 AI，先到「AI 服务」添加服务
   （如 DeepSeek：选预设 → 填 Key → 模型 `deepseek-chat` → 测试连接 → 保存并设为默认），
   再玩带 ✨ AI 节点的剧本或「忆城」导演模式。

> 编译要求：`minSdk 26`，`compileSdk 34`，`targetSdk 34`。请在 **Android Studio** 中编译运行
> （本工程由 AI 生成，未经本地工具链编译验证；如个别 API 在新版本有差异，以编译器提示为准微调）。

## 4. 无 AI 也能玩 / 玩法模型

- **分支剧本（离线）**：作者写死节点与选项 → 引擎按条件/效果/掷骰推进。
- **AI 场景节点（✨）**：进节点时把「最近剧情 + 变量快照 + 角色卡 + 节点指令」交给所选 AI，
  生成正文与动态选项；可设「结束后回到主线」的出口。没配服务时给出友好提示并自动跳主线。
- **AI 导演（自由）**：AI 每次根据历史与角色人设续写，玩家可自由输入或点灵感选项。
- 写法约定：正文支持 `\${变量}`（在 JSON 里写 `${变量}`）；角色说话建议写「名字：台词」；
  变量命名建议 ASCII（如 `intimacy`），在编辑器里中文变量名亦可。

## 6. 已知取舍

- 为保证工程轻量未引入 Hilt/Room：依赖注入手写，数据以 JSON 存私有目录。
- AI 生成会使用 `historyWindow` 条最近记录做上下文，过长历史自动截断。
- 存档在流式生成期间不可“暂停保存”当前半句；完整落盘后再存即一致。
- 节点编辑器默认按「叙述→选择→叙述」范式；AI 节点不手写分支（动态生成），
